# Deepam

Нативное приложение для iPhone: **стих из Бхагавад-гиты на каждом экране** — на экране блокировки, на рабочем
столе, в StandBy, в Центре управления и (по желанию) перед лентой соцсети. Санскритский оригинал в деванагари
(по умолчанию выключен) и английский перевод Анни Безант (1922, общественное достояние). Без аккаунта, без рекламы,
работает без сети.

Рабочее название — **Deepam** (санскр. «светильник»). Это заглушка: название надо проверить на занятость в App Store
и среди товарных знаков (см. `docs/FIRST-BUILD.md`).

Приложение собрано из основы, на которой уже выпускались приложения со стихом дня (Swift 6, SwiftUI, WidgetKit,
пакет SPM), с новым содержанием: другой корпус, другая палитра, вся графика нарисована заново.

## Что внутри

```

  make_project.py         генератор Deepam.xcodeproj (источник истины — он, не руки)
DeepamCore/               пакет SPM
  Sources/DeepamCore      движок, корпус, строки, настройки, уведомления (без UI)
  Sources/DeepamUI        экраны SwiftUI, шрифты, фоны, онбординг
  Sources/DeepamWidgets   виджеты (экран блокировки, рабочий стол, StandBy), кнопка Центра управления
  Sources/DeepamPurchases подписки (RevenueCat) — отдельно, чтобы не попадали в виджет
  Tests/                  тесты движка, корпуса, строк, оформления
tools/
  corpus/                 скачивание и сборка корпуса (санскрит + перевод), отбор стихов
  i18n/                   таблица строк интерфейса → Strings.swift
  art/                    графика, нарисованная кодом: фоны, иконки, арт онбординга
  legal/                  политика конфиденциальности, условия, поддержка → docs/legal
corpus-src/               исходные тексты Гиты, из которых собирается корпус
docs/                     лицензии, источники текстов, чек-лист первого выпуска, юридические страницы
codemagic.yaml            сборка и отправка в TestFlight
.github/workflows/ci.yml  проверка на macOS: тесты пакета и сборка приложения
```

## Палитра

Тёмно-красный и оранжевый: в индуистской традиции это чистые, благоприятные цвета (шафран, киноварь, кумкум). Чтобы
выглядело дорого, красный взят глубокий — гранат и бордо, а не яркий; оранжевый и матовое золото — только как свет:
пламя светильника, акценты, тонкие линии мандалы. Основы — `#1C0A0E`…`#3C141C`, оранжевый акцент — `#F0913A`,
золото — `#E6B866`, текст — тёплый слоновый `#F4E8DC`. Цвета наборов оформления — `DeepamCore/Sources/DeepamCore/Appearance.swift`,
цвета онбординга — `enum OB` в `DeepamUI/Onboarding.swift`, фоны и иконки рисуются кодом (`tools/art`).

## Содержание корпуса

168 отрывков (один–три стиха) по шестнадцати состояниям: тревога, страх, утрата, благодарность, прощение, сожаление,
доверие, надежда, бессонница, усталость, начало дела, решение, сомнение, одиночество, слабость, преданность.
К каждому — справка: глава, кто говорит и кому. Подробности, источники, исправления и пределы — в
[`docs/TRANSLATIONS.md`](docs/TRANSLATIONS.md). **Подборка стихов по состояниям — черновик и ждёт вычитки человеком,
знающим Гиту.**

## Как пересобрать данные

Python 3.12 (нужны `numpy`, `Pillow`, `scipy`, `beautifulsoup4`, `lxml`). Из корня репозитория:

```bash
python tools/corpus/fetch_gita.py      # скачать тексты в corpus-src/ (нужна сеть, ~20 запросов)
python tools/corpus/build_corpus.py --report   # собрать corpus-en.json и сверить санскрит
python tools/i18n/gen_strings.py       # пересобрать Strings.swift
python tools/art/build_assets.py       # перерисовать фоны, иконки и арт онбординга (~1 мин)
python tools/legal/build_legal.py      # собрать юридические страницы в docs/legal
python App/make_project.py             # пересобрать Deepam.xcodeproj
```

Предпросмотр одной картинки: `python tools/art/preview.py himalaya 440 out.png` (имена фонов — в
`tools/art/scenes.py`, иконок — `icon-default`, `icon-om` и так далее).

## Сборка

Компилятор Swift нужен только для самой сборки, поэтому всё проверяется на macOS:

- **GitHub Actions** (`ci.yml`) на каждый пуш в `main`: `swift test` пакета, сборка пакета под iOS-симулятор и
  сборка приложения с расширением. Логи каждого прогона публикуются в ветку `ci-logs` (репозиторий публичный,
  секретов в логах нет).
- **Codemagic** (`codemagic.yaml`): сборка `.ipa` и отправка в TestFlight по тегу `build-*` или кнопкой.
  Для первой сборки нужно завести приложение в App Store Connect и вписать его Apple ID (см. ниже).
